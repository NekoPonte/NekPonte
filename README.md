**NekoPonte** é um programa para Windows que permite acessar seu Foundry VTT pela internet através de um link, sem precisar de Radmin ou configurar portas no roteador. Com uma interface temática de gatinha, oferece um link temporário automático ou um endereço fixo usando um domínio e túnel configurados na Cloudflare. Basta abrir o Foundry, iniciar a ponte e compartilhar o link com os jogadores. O computador e os dois programas precisam permanecer ligados durante a sessão.
